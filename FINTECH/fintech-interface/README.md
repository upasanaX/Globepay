# GlobePay — Frontend Application

Modern React + TypeScript single-page application for the **GlobePay** global 1-tap scan and payment platform.

## Features
- **Universal 1-Tap QR Scanner**: Interactive camera viewfinder with multi-currency recognition and instant settlement.
- **Enterprise Landing Page**: Clean, professional presentation with instant demo access, live FX rates calculator, and fee comparisons.
- **Multi-Currency Management**: Visual multi-wallet cards with live balance synchronization.
- **Virtual Card Controls**: Dynamic freeze/unfreeze controls and spending limit configurations.
- **JWT Session State**: Centralized auth state with automatic 401 retry and token refresh interceptors.
- **Dark / Light Mode**: Seamless theme toggling powered by Tailwind CSS and Framer Motion.

## Available Scripts

In this directory, you can run:

### `npm start`
Runs the app in development mode on [http://localhost:3000](http://localhost:3000).

### `npm run build`
Bundles the app for production into the `build/` folder.

### `node server.js`
Serves the production build locally on [http://localhost:5000](http://localhost:5000).
